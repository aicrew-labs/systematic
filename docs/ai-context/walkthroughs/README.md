# AI Context Walkthroughs

This folder holds historical, chronological walkthrough logs generated at the end of significant tasks. 

---

## 📝 Walkthrough File Format

When you finish a task, instruct the AI to write a walkthrough in this folder using this naming convention:
`walkthrough_YYYYMMDD_[brief_description].md` (e.g., `walkthrough_20260518_setup_git_context.md`).

The file should contain:
1. **Goal:** What task was undertaken.
2. **Changes Made:** A concise list of new, modified, or deleted files.
3. **Verification:** Steps taken to verify that it works (e.g., test outputs, manual terminal checks).
4. **Next Steps:** What the next developer should focus on.
